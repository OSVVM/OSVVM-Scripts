.. _SUPPORT:

Support
#######

Get support for :acs:`OSVVM` at `osvvm.org <https://osvvm.org/>`__, or through the following channels.

.. topic:: OSVVM Forum

   OSVVM offers a `forum <https://osvvm.org/forums/forum/os-vvm>`__ with an active community.

.. topic:: OSVVM Discussions

   For interactive discussions, see OSVVM's Gitter channel
   `OSVVM Lobby <https://app.gitter.im/#/room/#OSVVM_Lobby:gitter.im>`__.

.. topic:: Reporting Bugs

   In case of a bug, please create a **problem report** at
   `OSVVM's issue tracker <https://github.com/OSVVM/OsvvmLibraries/issues>`__.

.. topic:: Suggesting Enhancements

   For missing features or suggestions, please create a **feature request** at
   `OSVVM's issue tracker <https://github.com/OSVVM/OsvvmLibraries/issues>`__.

   OSVVM is open for contributions via GitHub **pull requests**.

   .. hint::

      For bigger contributions or modifications to OSVVM's code base, please first open a **feature request** in the
      issue tracker, to discuss the proposed solution and how to integrate the changes into OSVVM's existing code.
